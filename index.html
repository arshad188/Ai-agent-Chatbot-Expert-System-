🏥 Expert Systems

IF-THEN rules that mimic human expertise.

Key Concepts:
  • Knowledge Base = All rules
  • Inference Engine = Applies rules
  • Explainable = You can trace decisions
# Simple Expert System
rules = {
    ("fever", "cough"): "Flu",
    ("fever", "rash"): "Measles",
}

def diagnose(symptoms):
    for (s1, s2), result in rules.items():
        if symptoms.get(s1) and symptoms.get(s2):
            return result
    return "See a doctor"

💬 Chatbots

Conversational interfaces that understand language.

Key Concepts:
  • Intent = What user wants
  • Entity = Specific details
  • Context = Conversation memory
import random

class Chatbot:
    responses = {
        "hi": ["Hello!", "Hi!"],
        "bye": ["Goodbye!"]
    }
    
    def reply(self, msg):
        for key in self.responses:
            if key in msg.lower():
                return random.choice(self.responses[key])
        return "I don't understand"

🤖 AI Agents

Autonomous systems that achieve goals using tools.

Key Concepts:
  • Autonomous = Works without guidance
  • Tools = APIs, search, databases
  • Planning = Breaks goals into steps
class Agent:
    tools = {"search": search_api}
    
    def run(self, goal):
        print(f"Goal: {goal}")
        result = self.tools["search"](goal)
        return f"Done: {result}"
