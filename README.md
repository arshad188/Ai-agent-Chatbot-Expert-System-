# AI Paradigms: From Rules to Autonomy

A comprehensive educational module teaching Expert Systems, Chatbots, and AI Agents through hands-on coding.

## 🎯 Learning Objectives
- Build a rule-based expert system from scratch
- Create both rule-based and generative chatbots
- Develop an autonomous AI agent with tool-use capabilities
- Compare strengths/weaknesses of each paradigm
- Deploy a hybrid application using Streamlit
